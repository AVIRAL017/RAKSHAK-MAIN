3. Instructions

If APIs are working but you don't see features on the main page:

  1. Hard Refresh your browser:
    • Windows: Ctrl + Shift + R or Ctrl + F5
    • Mac: Cmd + Shift + R
  2. Clear Browser Cache:
    • Chrome: Settings → Privacy → Clear browsing data
    • Firefox: Options → Privacy → Clear History
  3. Open Browser Console (F12) and look for errors
  4. Wait 30-60 seconds after page load for all data to load

4. What to Look For

On the main page, you should see:

  • ✓ Layer control menu in top-right corner with 4 checkboxes
  • ✓ Red hospital markers (plus sign icons)
  • ✓ Blue police station markers (shield icons)
  • ✓ Orange ambulance markers (ambulance icons, pulsing)
  • ✓ Existing accident hotspot markers
